# 🏡 My Digital Garden (数字花园)

> 一个基于 GitHub Actions + VitePress 驱动的纯前端、云端、高度自动化的个人笔记管理系统。

这是一个为自己量身打造的知识库架构。摆脱了传统笔记软件的笨重客户端，无需后台数据库，完全以 Markdown 格式托管于 GitHub。结合 VitePress 的极速编译与 GitHub Actions 的自动化流转，实现了**前台沉浸式写作 -> 云端自动归档 -> 网页极速呈现**的完美闭环。

## ✨ 核心特性

- 🤖 **全自动模块引擎**：前台写作保存路径即为分类，系统底层 Node.js 脚本自动扫描构建目录与侧边栏，无需手动维护任何配置代码。
- ⏳ **Git 原生时间轴**：摒弃不靠谱的文件系统时间，直接调用底层 `git log`，精准抓取每篇笔记的真实修改记录，并按最新时间自动排序。
- ✍️ **内嵌 API 写作台**：摆脱 GitHub 后台限制，直接在网页前端调用 GitHub REST API 完成 Markdown 撰写与提交，真正的沉浸式流转。
- 🛡️ **安全状态隔离**：定制化的 `DirectoryView` 前台目录，默认开启纯净阅读模式。只有开启“⚙️ 整理”开关后，才唤醒前台 API 彻底销毁功能，双重防误删。
- 📱 **极致移动端体验**：深度优化的折叠面板、全链路检索过滤与响应式排版。

## 🏗️ 目录结构说明

```text
.
├── .github/workflows/   # 核心：自动部署剧本 (GitHub Actions)
├── .vitepress/
│   ├── config.mts       # 核心引擎：包含动态抓取模块与 Git 时间轴排序逻辑
│   └── theme/
│       ├── components/  
│       │   ├── WebEditor.vue      # ✍️ 前台写作台 (API 提交核心)
│       │   └── DirectoryView.vue  # 📚 智能分类目录面板 (检索、折叠、管理)
│       └── index.js     # 全局组件注册注入
├── directory.md         # 笔记分类目录入口页
├── write.md             # 前台写作台入口页
├── index.md             # 网站首页主轴
└── [自定义分类文件夹]/    # 你的所有笔记 (由前台输入路径时自动生成)
```

## 🚀 如何使用 (Workflow)

1. **阅读与查找**：
   直接访问生成的 GitHub Pages 网址，在主页点击**开始阅读**进入目录。支持全局全文搜索，或在目录页使用关键字精准检索特定笔记。
   
2. **前台写作发布**：
   - 点击顶部导航栏或首页的 **✍️ 开启创作**。
   - 输入并保存一次个人的 GitHub Personal Access Token (本地记忆)。
   - 在路径框输入 `你想要的分类名/你的笔记名.md`（如 `英语精读/新词汇积累.md`）。
   - 编辑正文，点击发布。系统会自动在云端建文件夹，约 1 分钟后页面自动更新。
   
3. **前台管理与清理**：
   - 在笔记目录页面，点击右上角 **⚙️ 整理** 按钮。
   - 找到想要丢弃的笔记，点击 **删除**，弹窗确认后系统将通过 API 直接发送销毁指令。
